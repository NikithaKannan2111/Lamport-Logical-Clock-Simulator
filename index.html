Lamport Logical Clock Simulator

Visualize event ordering and message passing across distributed processes.

How it works: Each process has a logical clock. An internal or send event increments its clock by 1. On receiving a message timestamped T, the receiver updates its clock to max(local clock, T) + 1.

Algorithm reference

  1. Before every local/internal event, increment the process clock by 1.
  2. Before sending a message, increment the sender clock and attach that timestamp to the message.
  3. When receiving a message with timestamp T, set the receiver clock to max(receiver clock, T) + 1.
  4. The resulting timestamps respect the “happened-before” relation.
